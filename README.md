# pylrn — мой путь в Python-разработку

Цель: перейти от учебных задач к самостоятельным проектам и подготовиться к оплачиваемой стажировке.

Иду по порядку, не учу всё одновременно. Отмечаю пункт, когда могу применить его самостоятельно и объяснить свой код.

## Основные цели

- [ ] Python: функции, списки и словари, файлы, исключения, модули и виртуальное окружение.
- [ ] Продвинутые основы Python: ООП, генераторы, декораторы и контекстные менеджеры.
- [ ] Качество кода: PEP 8, аннотации типов, понятные имена и небольшие функции.
- [ ] Git: коммиты, просмотр изменений, ветки и работа с GitHub. Изучаю параллельно с Python.
- [ ] Основы Linux: команды терминала, файлы, каталоги и запуск программ.
- [ ] SQL и PostgreSQL: базовые запросы, JOIN, группировки, подзапросы, оконные функции, индексы и основы оптимизации.
- [ ] Pandas и NumPy: чтение, очистка, фильтрация, объединение и обработка данных.
- [ ] FastAPI: основы HTTP и JSON, создание API, проверка данных и подключение базы.
- [ ] Lakehouse: общее представление об архитектуре и отличиях от классического хранилища данных.

## Дополнительные цели — после основы

- [ ] Основы контейнеризации и Docker.
- [ ] Основы асинхронного программирования на Python.
- [ ] Форматы Parquet и ORC, табличный формат Iceberg.
- [ ] S3-совместимые хранилища: попробовать MinIO, AWS S3 или VK Cloud.
- [ ] Apache Airflow: запуск и оркестрация пайплайнов обработки данных.
- [ ] Знакомство с Apache Spark (PySpark) или Dask.
- [ ] Знакомство с Trino или Presto.
- [ ] Знакомство с dbt или Cosmos из требований вакансии.

## Практический результат

- [ ] Самостоятельно собрать небольшой проект с обработкой данных, PostgreSQL и FastAPI.
- [ ] Добавить автоматические тесты и понятную инструкцию по запуску.
- [ ] Уметь объяснить устройство проекта и самостоятельно изменить его функциональность.
